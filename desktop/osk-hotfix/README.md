# TB710FU 0.3.0 屏幕键盘补丁

离开密码框后，普通输入恢复中文候选和拼音组合输入。密码框仍获得焦点时及锁屏时，候选不会显示。符号键盘保留四排，Tab、Shift、Ctrl、Alt 和方向键与中英文主键盘对齐。原 Esc 位置的「中符」「英符」用于切换两套标点。点右侧「⇧ []{}|」可打开第二页，直接输入括号、竖线和 ≤、≥、≠。

在平板上解压发布附件，进入解压目录运行：

```bash
python3 install.py
sudo python3 install.py --apply
```

原版 0.3.0 和已安装早期版本屏幕键盘补丁的设备均可安装。脚本校验四个文件，并将需更新的旧文件备份到平板本机的 `/var/backups`。安装后保存工作，注销并重新登录，让 GNOME 加载新代码。
