# TB710FU 从 0.1／0.2 迁移到 0.3

本迁移包使用已发布的 0.3.0 预览系统镜像和启动镜像。适用于官方 0.1.0 或 0.2.0 的 TB710FU Ubuntu 单系统安装，要求原有 Ubuntu 位于唯一的 `arch` ext4 分区，账户家目录位于同一分区的 `/home`，且启动镜像和固件通过预检。

1. 先把重要个人文件和设置备份到另外的设备。在旧 Ubuntu 和 Windows 上各解压同一份迁移包。Ubuntu 端保留解压后的目录结构，在迁移包根目录打开终端，运行以下命令：

   ```bash
   sudo python3 migration/check-ubuntu.py --backup-boot .
   ```

2. 将生成的 `boot-before.img` 复制到 Windows 解压目录的根目录，与 `manifest.json` 放在一起。它是用于恢复旧启动镜像的本机备份，按个人备份保存。
3. 将平板重启进入 fastboot 后连接 Windows。电脑需要网络、fastboot 驱动和至少 40 GiB 可用空间。运行 `windows\migrate-to-030.cmd`，核对提示并输入 `KEEP`。迁移器下载并校验 0.3.0 镜像，保留旧 Ubuntu 的账户、密码和 `/home` 数据。
4. 正常完成后用旧账户登录，检查个人文件与设置。系统软件、系统级配置和应用的安装记录会按 0.3 镜像更新。依赖旧系统软件的应用可能需要重装。

预检失败时请停止。迁移会先写入临时启动镜像，成功后再写入 0.3 启动镜像。如果中断，已校验的旧启动镜像可用于救援，但仅恢复启动镜像无法撤销已经覆盖的系统文件。此版本经过离线验证，Windows 实机覆盖和重启仍待验证。
