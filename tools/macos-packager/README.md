# TB710FU Ubuntu macOS 打包工具（预览）

在这台 Mac 上双击“TB710FU Ubuntu 打包工具.app”，连接已启动 Ubuntu 的 TB710FU，选择输出目录，点击“开始打包”并输入平板管理员密码。密码只用于本次 SSH sudo 认证，不写入安装包。需要 Mac 已配置可用的 `tb710fu-usb` SSH 连接，并有 Xcode 命令行工具提供的 `/usr/bin/python3`；平板至少需要约 70 GiB 可用空间，Mac 输出磁盘至少需要 50 GiB。

工具从平板系统创建单独镜像，不格式化或重装平板。它排除用户家目录、账户密码、网络配置、主机密钥、日志、设备备份、Android 用户数据和 Snap 用户状态，并对常见个人标识进行检查。镜像保留修复助手和 Google Chrome，并排除 Chrome 的用户资料、浏览记录、缓存和设备管理策略；QQ、WorkBuddy、FlClash 不进入发行镜像。Chrome 再分发权限需另行核实。构建成功后设备端大型临时镜像会删除；如果中途失败，工作区可能留在设备上，请检查程序日志并按需清理。

目前只支持审核过的 TB710FU `7.2.6-tb710fu-20261118` 内核和固定启动镜像，且电源、背光、输入法和安卓窗口扩展必须与随程序提供的审核版本一致。校验不通过会停止；以后这些组件变化时需要更新并重新审核工具。普通个人设置、用户安装的 Snap 和没有列入审核范围的用户级定制不会自动复制。退休的前摄实验目录不会作为构建输入。

输出为 Windows 离线安装 ZIP，包含安卓首次安装和受支持 Ubuntu 布局的保留数据覆盖选项。Windows 端到端安装、首次启动和保留模式尚需实机验证；保留模式也会先覆盖启动分区，检查失败可能需要恢复启动镜像。对外分享前，请自行审核镜像内容及第三方软件、固件许可。已知特征扫描不能证明不存在所有个人数据或压缩文件内的秘密。

此应用为本地构建的预览版，不会自动上传 GitHub。源码位于同目录；`build-app.py` 从当前工作区的明确文件清单生成自包含应用，需重新构建才能带入源码或审核输入的更新。
